# 木材さわってラボ

中学1年 技術「材料と加工の技術／木材の特性」を、さわって確かめる学習ページです。

- ① 名前：丸太の切り口・板・木取りの各部をタップして名前を調べる（名前あてチャレンジ付き）
- ② 重さ：樹種ごとの10cm角の重さ、水に浮かべた様子、細胞のすき間の割合
- ③ 強さ：木目の向きを変えて、おもりを何個のせると折れるか
- ④ 乾燥：丸太の上で板を動かし、乾燥による反り・割れを見る
- ⑤ 木質材料：単板の重ね方を変えて、合板・集成材のつくりを確かめる
- ⑥ チェッククイズ

登録不要・通信なし（フォント以外）・単一HTML。数値は学習用のめやすです。
